# GameOfLife
Proiect de laborator (PCBE/CEBP): 'Jocul Vieții'. 
O simulare concurentă în Java unde celule (ca fire de execuție) caută hrană, se reproduc (sexuat/asexuat) și mor. 
Resursele partajate (harta lumii, hrana) sunt gestionate folosind ConcurrentHashMap și synchronized pentru a asigura siguranța firelor de execuție.
